# Bikou 微光 — Android 测试版

只放安装包，源码仓库保持私有。

## 下载

到 [Releases](https://github.com/wdz316/bikou-releases/releases) 页面下载最新的 `.apk`。

安装说明：

1. 用手机浏览器打开下载链接（微信里点开会多一层限制，建议转到浏览器）
2. 系统提示「未知来源」时允许安装
3. 打开后点「开始记录轨迹」才会定位；精确轨迹只存在本机，不上传

## 测试反馈

装完回三句话就够：

1. 安装和第一次打开，有没有卡住或害怕的地方？
2. 走完一段路回到地图，第一眼是什么感觉？
3. 哪一步最想放弃？

## 说明

- 火柴（匹配）需要两个人在同一片街区走过同一条路才会点亮，异地不会触发
- App 内有一个明确标注「示例」的演示火柴，可以先看流程
